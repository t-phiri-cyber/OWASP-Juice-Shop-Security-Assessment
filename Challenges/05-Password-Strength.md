# 05 — Password Strength

**Security area:** Authentication and password security  
**Application:** OWASP Juice Shop 20.3.0 (local instance)

## Objective

Complete the Password Strength challenge and consider the risks created by weak or compromised passwords.

## Security significance

Weak, reused or previously compromised passwords increase the likelihood of account takeover. Password controls should assess password quality and prevent known-compromised credentials from being accepted where feasible.

## Recommended remediation

- Enforce sensible minimum password requirements without relying solely on arbitrary complexity rules.
- Screen new passwords against known-compromised password lists using privacy-preserving methods.
- Rate-limit authentication attempts and monitor suspicious login activity.
- Support multi-factor authentication, especially for privileged accounts.
- Encourage unique passwords and use of password managers.
- Store passwords using a modern adaptive password-hashing algorithm with unique salts.
